# cv/

Tüm grup üyelerinin CV'leri bu klasörde tutulur.

## Adlandırma kuralı

Dosya adı: `Ad_Soyad_CV.pdf`

- Boşluk yerine alt çizgi kullanın.
- Türkçe karakter yerine ASCII harf kullanın (örnek: `ı` yerine `i`, `ğ` yerine `g`, `ü` yerine `u`).
- Örnek: `Zeliha_Ilgin_Guven_CV.pdf`

Bu klasör bilinçli olarak boş bırakılmıştır. Üyeler CV'lerini kendileri ekleyecektir.
