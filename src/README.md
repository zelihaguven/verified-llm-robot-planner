# src/

Kaynak kodlar bu klasörde tutulacaktır. Henüz uygulama kodu yoktur.

Alt klasörler taslak mimariye göredir:

- [language/](language/): doğal dil komutu ve LLM görev yorumu
- [perception/](perception/): algılama ve görsel-dil (VLM) girdileri
- [planning/](planning/): görev planlama (aday plan, HTN veya benzeri)
- [verification/](verification/): plan doğrulama ve grounding
- [execution/](execution/): deterministik yürütme (Behavior Tree)
